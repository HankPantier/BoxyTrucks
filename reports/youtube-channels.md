# YouTube channels added to model pages

Date: 2026-10-22. Scope: the 23 model guides that had no YouTube channels, then any model page with fewer than 3.

**How each channel was checked:** I fetched `https://www.youtube.com/@handle/videos` with the BoxyTrucksBot user agent. For each channel I confirmed that the page exists, that it returns the channel title and channel ID shown below, and that its description or recent video titles cover the model. Dates such as "2 months" are YouTube's relative upload ages as of the fetch. I found candidates with YouTube's own search results page, not the shared web search. Duplicates were checked by channel ID, so a channel already listed under a `/channel/UC…` or `/user/` URL was not added again. I only added entries; nothing was removed or changed.
