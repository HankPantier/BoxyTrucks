# YouTube channels added to model pages (round 2)

Date: 2026-10-27. Scope: 15 model guides with no YouTube channels (trooper-1, trooper-2, prado-90/120/150, k5-blazer-1st, suburban-square, lj-series, jimny-jb23, jimny-jb74, patrol-60, y62, wagoneer-ws, g63-6x6), plus topping up the flagships of the newer families (chevrolet → k5-blazer, suzuki → samurai, pajero → pajero-gen2, trooper → trooper-1, hummer → h1) to at least 3 channels.

**How each channel was checked:** I found candidates with YouTube's own search results page. Then I fetched `https://www.youtube.com/@handle/videos` with the BoxyTrucksBot user agent and read the channel title, channel ID, description and the recent uploads from the page data. Where a title didn't show the model generation, I opened the video page and read its description. Ages such as "2 months" are YouTube's relative upload ages as of the fetch. I checked duplicates against every YouTube URL in `data/`, by handle and by channel ID; no new channel was already on the same page or in the same family hub. Velocity Restorations is already listed for bronco and scout, but not for chevrolet. I only added entries. Nothing existing was removed or changed.
